# 认知递归与内在记分卡

认知升级 Skill——融合「AI 递归学习法」与「内在记分卡」两大认知工具（Cognitive Recursion & Inner Scorecard）

## 项目解决什么问题

学了很多但不成体系、容易被外在记分卡（金钱、地位）牵着走；年度规划与复盘缺少认知框架支撑。本技能把"自上而下、问题驱动"的递归学习法与巴菲特式"内在记分卡"结合，用于个人成长路径设计。

## 主要功能

| 能力 | 说明 |
|------|------|
| AI 递归学习法 | 三层追问法、问题驱动、自上而下学习、风险控制 |
| 内在记分卡 | 核心定义、消费参照系切换、内在记分卡三问（目标拷问）、巴菲特标准 |
| 融合心法 | 年度规划三层结构（从方法论到心法） |
| 思想家视角 | 项飙/李希贵/韩炳哲/鲍曼/波兹曼/佛罗里达视角的深度反思提示词策略 |
| 年度复盘 | 复盘问题清单（references/annual-review-questions） |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：AI 递归学习法、内在/外在记分卡、年度规划/年度总结/年度复盘、消费决策校准、项目目标筛选、思想家视角深度反思。

## 输入输出示例

**输入：** 用内在记分卡三问拷问这个项目目标
**输出：** 三问结论 + 目标调整建议

**输入：** 帮我做年度复盘
**输出：** 按复盘问题清单输出的年度复盘文档结构
